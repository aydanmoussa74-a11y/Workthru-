# Training Rules & Principles

## Movement Standards
1. **Full Range of Motion:** Emphasize joint safety, controlled eccentric phases, and active bracing.
2. **Adaptive Ladders:** Each movement pattern (push, pull, squat, hinge, lunge, plank) offers 5 progression tiers.
3. **Rest Intervals:** Timed transitions and rest periods dynamically adjust based on user readiness and session intensity.
4. **Session State Transitions:**
   `NOT_STARTED` → `PREPARING` → `ACTIVE` ↔ `REST` → `COMPLETED` / `ABANDONED`
